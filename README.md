Explainable AI-Driven Multimodal Analytics for Sustainable Smart City Decision Intelligence
Overview
This project develops an AI-driven analytics framework that integrates Air Quality, Weather, and Energy Consumption data for sustainable smart-city analysis. Machine Learning models are used for prediction and comparison, while Explainable AI (SHAP) helps identify the factors influencing predictions. An interactive dashboard presents the results and insights for data-driven decision-making.
Objectives
- To develop an interactive analytics platform for environmental and energy analysis.
- To integrate Air Quality, Weather, and Energy Consumption data to identify meaningful relationships and patterns.
- To enhance predictive analytics using Explainable AI (SHAP).
- To evaluate and compare Machine Learning models for environmental and energy prediction.
Datasets
- Air Quality Dataset
- Weather Dataset
- Energy Consumption Dataset
Machine Learning Models
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- LightGBM
- CatBoost
Explainable AI
SHAP is used to explain model predictions and identify the important factors influencing the results.
Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score
Workflow
Data Collection → Data Cleaning → Data Integration → EDA → Feature Engineering → Machine Learning → Model Evaluation → Explainable AI → Interactive Dashboard
Technologies
Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, CatBoost, SHAP, Matplotlib, Seaborn, Plotly, Streamlit, Jupyter Notebook, Git, GitHub
Innovation
The project brings environmental, climate, and energy analytics together with Machine Learning, Explainable AI, and interactive visualization in a unified framework for sustainable smart-city decision intelligence.
Future Scope
The framework can be extended with real-time data, IoT sensors, advanced AI models, additional sustainability indicators, and real-time recommendations.
